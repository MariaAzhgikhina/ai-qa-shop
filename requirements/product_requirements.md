# Product Requirements

## REQ-001
The catalog must display all available products with a name, price, category, and stock status.

## REQ-002
A user must be able to open a product page and read its full description.

## REQ-003
A user must be able to filter catalog products by category.

## REQ-004
A user must be able to sort catalog products by price in ascending or descending order.

## REQ-005
The shop must show a clear message when a requested product does not exist.

## REQ-006
A user must be able to add an available product to the shopping cart.

## REQ-007
A user must be able to change the quantity of an item already in the cart.

## REQ-008
A user must be able to remove an item from the cart.

## REQ-009
The cart must display the total price of all selected items.

## REQ-010
The cart must not accept zero or negative item quantities.

## REQ-011
A user must not be able to select more units than are currently in stock.

## REQ-012
The cart contents must remain available while the user navigates between shop pages.

## REQ-013
Checkout must collect the customer's name, email, and delivery address.

## REQ-014
The shop must validate the customer's email before accepting an order.

## REQ-015
An empty cart cannot be submitted as an order.

## REQ-016
The shop must verify product availability when checkout is submitted.

## REQ-017
A successful checkout must create an order, reduce product stock, and clear the cart.

## REQ-018
After checkout, the user must see a confirmation containing the order identifier.

## REQ-019
The API must return JSON errors with a stable error code and readable message.

## REQ-020
Prices shown during checkout should match the prices shown in the catalog.

## REQ-021
Maximum quantity of one product is 10.
